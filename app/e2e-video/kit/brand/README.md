# Brand files for the title cards

- `sora-latin-wght-normal.woff2` — Sora (variable, latin), the brand typeface
  of the Le Space Belege style guide, from `@fontsource-variable/sora` 5.3.0
  (Google Fonts build). SIL Open Font License 1.1. Embedded into the cards as
  a data URI: Chromium does not load a font file next to a page set with
  `setContent`.

The signet (coin and receipt) and the colours are in `../card.js`, drawn as in
the marketing site's `BelegeLogo.svelte` (landing repo, `sites/belege`).
